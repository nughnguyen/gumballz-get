# GumballZ Brutalist UI

- Use asymmetric Bento layouts with 16px gaps, 2px ink borders, 12px card radii, and 4px 4px 0 hard shadows.
- Use Electric Cyan `#22D3EE`, Donate Amber `#FBBF24`, and the dark/light palettes documented in `DESIGN.md`.
- Interactive controls shift by 2px on `:active` and reduce their hard shadow.
- Keep text contrast high, controls keyboard accessible, and layouts usable at the minimum desktop viewport.
- Never alter the signature, command name, or argument contract of any Rust `invoke(...)` command.
